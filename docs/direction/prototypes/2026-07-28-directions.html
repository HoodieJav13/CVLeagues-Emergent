Compare cold, at a squint, before deciding. (The unification decision — one device everywhere — stands regardless of which shape wins.)

Interventions, cheapest → most ambitious

Everything proposed anywhere in this pass, ordered by cost. Items 1–6 are individually smaller than any shipped batch. Items 10+ are deliberately beyond what was asked for — priced so they can be rejected consciously rather than never seen.

  1. Copy pass — give the app a voice

    ~20 strings: "All Containers" → "All Leagues", "the administrator" → "the league", empty states become editorial. No layout change.

    Cost: hours · Audit X2

  2. Form-chip + streak spec fix

    The logged finding: 20px chips, 11px text, full-opacity borders, `--leader-bg` contrast pass — executed inside item 6 rather than alone.

    Cost: hours · Standings finding

  3. Free Agent h1 wrap + "Download These Games" placement

    Two mechanical NON-BLOCKING fixes riding along with any batch.

    Cost: trivial

  4. Identity swaps (X1)

    Octagon replaces the Team-header square, GameCard dots, Playoffs dots, box-score dots; StatStrip replaces hand-rolled stat tiles. Existing primitives, ~6 files.

    Cost: 1 short batch · Top-3 #1

  5. Schedule mobile row rebalance (D1 or D2)

    Names stop truncating at 375; CSS-only in D1.

    Cost: 1 component · Top-3 #3 adjacent

  6. Standings recomposition (A1 or A2)

    Mobile content parity incl. the latent tie-honesty BLOCKING, bigger numerals, rail re-scoped. One page.

    Cost: 1 batch · Top-3 #2

  7. Game Detail recomposition (B1 or B2)

    Scoreboard-as-title, single state grammar, forfeit/tie design, optional team-color fields.

    Cost: 1 batch · Top-3 #3

  8. Page signature in the capture zone (X3)

    Small wordmark + season on Standings/Game/Leaderboards so every player screenshot carries the brand.

    Cost: 1 shared component

  9. Home arrival states (C1/C2)

    The hero computes from the schedule; game day exists. First candidate surface for Pass 5 motion.

    Cost: 1 batch

  10. Unkind fixture set + latent-state designs (X4)

    Owner-approved seed additions (tie, 0-0, forfeit, 38-char name, 2-enrollment franchise, populated bracket) plus FORFEIT/TIE visual language — makes five currently-unauditable states permanently auditable.

    Cost: 1 batch incl. seed governance

  11. Season-shape data graphics (A3)

    Differential worm on Standings, form sparkline on Team. Needs the data-graphic vs decorative-chart contract amendment.

    Cost: medium · Amendment

  12. Match poster hero (B3)

    Full-viewport shareable game frame; the social object designed as one.

    Cost: medium · Amendment

  13. Per-entity OG cards

    Team/player/game links unfurl with real identity in group chats — where the league actually markets itself. Needs serverless render at deploy time.

    Cost: high · post-deployment infrastructure

  14. Sunlight/outdoor legibility variant

    A high-contrast mode for Schedule + Game Detail (the on-field surfaces): larger minimums, no sub-60% opacity signals, optional light surface. The dark canonical surface is a locked decision — this would amend it deliberately, priced against a real phone-in-the-sun test.

    Cost: high · Amendment + research

  15. Public live scoring day (with the flag-football pilot)

    The palette's most aggressive color is reserved for LIVE and LIVE never happens publicly. If the ledger pilot ever feeds a public surface, game day becomes the product's defining moment — red earns its reservation, and the Pass 5 motion budget has its stage.

    Cost: product decision + full stack · far beyond this pass

Reference material that would beat another named app: any broadcast score-bug/lower-third design system (the compressed team-color + numeral grammar B2 borrows), and one real photo of a CVF game night — a single usable photo would resolve the fallback-vs-photography question better than any anchor discussion.
